# Persona test: ordinary staff user (Teacher role), 2026-10-15

Ledger: `persona-user-2026-10-15`. Tester persona: a member of teaching staff who only books rooms (classroombookings "Teacher" role: `book_single.create`, `room.view`, `book_*.view_other_notes`). Most of the run was in Turkish; the key flows were repeated once in English.

## 1. BLUF

- **No blockers. 7 major and 18 minor issues.** A teacher can reserve, drag-reserve, multi-reserve, request an approval room, edit or cancel with scope, withdraw a request, subscribe to the ICS feed and find a room, in both Turkish and English and at 390 px.
- **The shell is still planner-shaped.** After login a teacher lands on an empty "Çizelge" page that offers "Program oluştur / Excel'den içe aktar" (U-02). The logo link and the `g d` shortcut open the planner dashboard, which shows a stack of "yetkiniz yok" toasts (U-03).
- **Two backend correctness bugs:** periods that already ended today can be booked, and the booking then cannot be cancelled (U-04). A user's own pending request does not show in the grid, so the same request can be sent twice (U-06).
- **Accessibility:** the keyboard focus ring is invisible on almost every control. This is a Tailwind v4 `outline-none` + `focus-visible:outline-2` pitfall in 57 files (U-01). Focus also falls to `<body>` after every successful action (U-07).
- **Password change silently signs you out.** The backend revokes the session, the UI does not notice, and pages then show false empty states and a raw "missing bearer token" error (U-05).
- **Motion is purposeful and reduced-motion/transparency work.** The frame budget fails on sheet open, next day and drag release, but the machine's load average was 23–31 on 4 cores, so these numbers need a re-run on a quiet machine (§4).
