# SmartSched status

The single "where are we" page. Everything between `AUTO` markers below is generated by
[`scripts/docs/sync_docs.py`](../scripts/docs/sync_docs.py) from the sources of truth, so it is never edited by
hand: change the source (named under each block), then run

```bash
python3 -I scripts/docs/sync_docs.py          # rewrite the stale blocks
python3 -I scripts/docs/sync_docs.py --check  # what pod CI runs (validate gate): exit 1 when a block is stale
python3 -I scripts/docs/sync_docs.py --list   # the blocks per file
```

Agents run the sync before every commit that touches a source (`docs/features.yml`, `docs/ROADMAP.md`,
`docs/agents/registry.json`, the parity report, a migration, `podci/gates.py`, the intake formats or the message
catalogues); otherwise the validate gate fails on the stale block. Text outside the markers is free prose and is
never rewritten.
